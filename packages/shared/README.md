# @katha/shared

Shared TypeScript types, constants, and utility functions used across all apps.

## Exports

- **Types**: `User`, `Story`, `Avatar`, `ApiResponse`, `AuthTokens`, etc.
- **Constants**: `SUPPORTED_LANGUAGES`, `PAGINATION_DEFAULTS`, etc.
- **Utils**: `truncate`, `isValidLanguageCode`, `formatDate`, etc.

## Usage

```typescript
import { User, SUPPORTED_LANGUAGES, formatDate } from '@katha/shared';
```
